Colour pass

Rendered from the same values now in main.dart, so what is below is what the app draws. One rule runs through all of it: the five traffic-light bands own “how well”, and nothing else is allowed to. Every new colour here is identity — which unit, which person, which class — and never changes with progress.

The eight unit colours

Each measures 4.5:1 or better against both white and the cream page, so each works as a fill under white text and as text on the background. Deliberately no green and no orange, so a unit tile can never be misread as “mastered” or “needs work”.

Units — before and after

Was eight identical white pills you had to read. Now each unit keeps one colour forever, seeded from its name so adding a unit never repaints the others. A lettered tile sat in front of each one for a while and has been cut — it repeated the first character of a word that was right beside it. Letters are for people now; colour alone is for things.
